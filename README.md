# 光电效应虚拟仿真实验 · 交付说明

> 利用 AI 制作轻量化虚拟仿真实验或动画 · 单人作业

## 文件清单

```
├── index.html          # 可运行的 H5 系统（单文件，含全部代码：物理引擎/渲染/AI/拟合）
├── README.md           # 本文件：交付说明与打包指引
└── docs/
    ├── 方案文档.md      # 选题背景 / 仿真目标 / 技术路线 / AI赋能思路 / 可行性说明 / 学术诚信声明
    ├── 用户手册.md      # 操作手册 / Ollama 接入指南 / 常见问题
    └── 部署指南.md      # GitHub Pages / Netlify / Gitee Pages 在线部署步骤（获取访问链接）
```

## 运行方式

- **本地运行**：双击 `index.html`（Chrome / Edge），或
  ```
  python -m http.server 8765   # 然后访问 http://127.0.0.1:8765/index.html
  ```
- **在线访问**：将 `index.html` 上传至任意静态托管（GitHub Pages 等）即为"访问链接"。

## 功能核对（对照评分标准）

| 要求 | 实现情况 |
|---|---|
| 可交互 | 波长/光强/电压滑块、5 种金属、自动测 U꜀、粒子动画实时反馈 |
| 可对话 | AI 实验助教（4 角色），支持文字 + 语音提问 + 语音播报 |
| 可评估 | 数据拟合求 h（R²/误差）、AI 数据分析、AI 报告评估、答辩教练 |
| 轻量化 | 单文件、零依赖、零后端；AI 三引擎按需降级（本地 Ollama → 在线 API → 内置离线智能） |
| 加分项 | 接入本地部署 LLM 实现完全离线 AI 能力；语音交互；WebXR VR 观察（原生 WebGL 实现，零依赖）；真实实验数据导入对照；数据持久化 / CSV 导出 / 报告打印导出 PDF |

## 打包提交指引

1. 将 `index.html`、`README.md`、`docs/` 打包为 ZIP；
2. 命名规则：**班级+姓名+学号.zip**（如 `物理2301_张三_2023xxxx.zip`）；
3. 附上在线访问链接与演示视频（选交）。

## 演示建议（答辩脚本，约 3 分钟）

1. 打开页面 → 顶栏展示 AI 引擎状态（本地 LLM 离线运行 = 加分项）；
2. 拖波长到 700nm → 电流消失 → AI 主动弹出红限纠错提示（体现"AI 深度融入"）；
3. 点击「⚡ 自动测 U꜀」测 3~4 个波长 → 数据页「拟合求 h」→ 展示相对误差；
4. 点「🤖 请 AI 分析数据」→ 展示情境感知回答（AI 能说出你当前的具体参数）；
5. 🎤 语音提问演示 → 生成报告 → AI 评估报告收尾。
